# Site fofo para a namorada — distância que não vence

Pronto para publicar no GitHub Pages.

## Estrutura

- `index.html` — mensagem e estrutura
- `style.css` — fundo rosa, fotos de fundo, corações, responsivo
- `script.js` — corações flutuantes e galeria
- `assets/fotos/` — fotos dela (`foto1.jpg` a `foto6.jpg`)

## Como publicar

1. Crie um repositório no GitHub (ex: `site-namorada`).
2. Envie todos esses arquivos para o repositório, incluindo a pasta `assets/fotos/`.
3. No GitHub, vá em **Settings → Pages**.
4. Em **Build and deployment**, branch `main`, pasta `/root`.
5. Salve. O site fica online em alguns minutos.

## Celular

O site é feito para abrir no celular: layout em coluna única, botões grandes, texto ajustável e fotos da galeria empilhadas ou lado a lado conforme a tela.
